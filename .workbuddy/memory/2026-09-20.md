## 执行：分镜表时码全量重排（commit `49e5575`，10 文件 +1626 −1408）

上一轮把「时码不自洽」列为全项目最贵的一处、判断"标题秒数是对的、时间码是错的"，本轮**把它证成了**并一次修完。

### 口径判定：标题秒数为准（四重印证）

1. `22` 号**分集总表逐集列出该秒数**（105s / 105s / 110s…），与脚本标题逐一对上
2. `22` 号 §零 / §145 记「40 集约 80–82 分钟」
3. `31` 号 §10.2 **对外**明写「漫剧 EP19 有 145 秒 / 88 个镜头」
4. **物理可行性**：全季对白 8372 字 ÷ 5 字/秒 = 27.9 分，加静音节拍 16.4 分 = 硬下限 **44.3 分** ≪ 标题总长 81.5 分；
   而**表格尺度下每集有 79% 的时长是空的** → 表格是错的一方

**反例佐证表格两个方向都错**：EP09 第 9 镜是全季招牌的「60 秒长镜头」（`24` 制作要点 + `31` 都写明），表格只给了 **20 秒**。

### 修法：新增 `docs/novel/tools/retime-shots.py`（内容驱动，非等比缩放）

- 每镜下限 = `max(1s, 对白字数/5.0, 行内任何「N 秒」标注)`
- **有标注 / 钉死的镜头取精确值，余量只分给无标注镜头**（保住作者的重音分布）
- **招牌镜头钉死**：EP09 第 9 镜 = 60 秒
- 余量按原镜长加权 + 最大余数法，总和精确

**结果：35 集精确等于标题秒数，40 集相邻镜零断裂，全季 5069 秒 = 84.5 分钟。**
