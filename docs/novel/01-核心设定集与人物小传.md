# 《代码视界》核心设定集与人物小传

> **系列定位**：热血少年向 · 都市技术幻想 · 群像成长
> **一句话简介**：一个连 CRUD 都写不利索的应届生，入职第一天就看见了整个互联网的"真身"。
> **副标题备选**：第一卷《未捕获异常》

## 一、为什么这个设定能同时做好小说、漫剧和游戏

在动手写第一行字之前，先把三条硬约束钉死。这是整个 IP 的地基：

| 需求 | 对应的设计决策 |
|---|---|
| **讲解生动、趣味性强** | 所有技术概念都必须有**可视化的实体形象**。内存泄漏不是一个术语，是一条越堆越高的垃圾街 |
| **极易做成漫剧** | 每个技术概念都有**统一的色彩语言和音效语言**，美术和音效团队拿到表就能开工 |
| **极易做成游戏** | 每一次线上事故 = 一个**有明确规则和胜负条件的副本**，技能树 = 真实技术栈 |

**最关键的一条**：本作有一条铁律——**视界只给眼睛，不给手**。

主角能"看见"系统的真相，但要让真相变成结果，他必须回到键盘前，写出正确的代码，说服正确的人，扛过正确的发版流程。

这一条同时解决了三个问题：
1. 不会变成无脑爽文（看见了不等于解决了）
2. 技术讲解天然必要（看不懂就解决不了）
3. 游戏化天然成立（情报优势 + 资源调配，而不是数值碾压）

## 二、世界观：代码视界（Code Vision）

### 2.1 起源：大静默

公元 2021 年 11 月 11 日凌晨 00:07，全球范围内，所有正在运行的互联网系统同时出现了一次持续 **1.7 秒**的完全静止。

不是宕机。是所有请求、所有线程、所有日志都停了 1.7 秒，然后一切恢复正常，没有任何数据丢失，没有任何官方解释。

那天之后，全球约 **0.003%** 的人开始"看见东西"。

他们看见的，是运行中的软件系统的**真形**。

这群人后来被称为 **观者（Watcher）**。这次事件被称为 **大静默（The Great Silence）**。

> **叙事功能**：大静默的真相是全书终极谜题。它同时是反派"静默者"组织的名字来源，是主角能力起源的解释，也是第三幕终极对决的核心。

### 2.2 视界分层：你能看多深，取决于你懂多少

这是全书最重要的成长体系。视界不是一次性给满的，它分五层，**清晰度严格等于技术水平**。

| 层级 | 名称 | 能看见什么 | 现实对应 |
|---|---|---|---|
| **L0** | **灰视（Dust）** | 只有一团模糊的光影和气色。绝大多数觉醒者终其一生困在这一层 | 完全不懂技术，只能感觉到"这系统好像不太行" |
| **L1** | **轮廓层（Outline）** | 看见建筑、街道、人流。能判断系统死活和大致负载 | 懂业务、懂运维表象。**孙野**在这一层 |
| **L2** | **结构层（Schema）** | 看见模块边界、依赖连线、数据流向。能定位问题**在哪一栋楼** | 熟练工程师。**赵大鹏**勉强触及，**沈青梧**是这一层的顶尖 |
| **L3** | **指令层（Bytecode）** | 看见每一条指令的执行，主观时间近乎静止。能精确定位到**哪一行** | 资深专家。**纪寒声**在这一层 |
| **L4** | **源码层（Source）** | 传说。能看见"这个世界本身的源代码" | **全书麦高芬，无人达到** |

**关键规则：看得见 ≠ 看得懂。**

一个不懂并发的人，即使视力再好，在视界里看到的线程池也只是"一群站着不动的人"。他看不出那是阻塞，更看不出阻塞在哪一行。

**懂得越多，看得越清。** 这就是本作的学习驱动力——读者会主动想知道"什么是阻塞队列"，因为主角看不懂，读者就着急。

### 2.3 视界三铁律

**第一律：视界只给眼睛，不给手。**
在视界中，你可以观察、可以移动、可以判断。你无法修改任何东西。想改变世界，回到现实，改代码，发版。

**第二律：越强越痛。**
开启视界消耗"精神带宽"。L1 可以撑两小时，L2 撑二十分钟，L3 只有几十秒。超时会出现：视野碎裂、耳鸣、流鼻血、短暂失语。严重者会**失视**——永久失去看见代码的能力。

**第三律：观者之间可以互相看见。**
两个观者在同一空间开启视界时，会看到对方身上淡淡的轮廓光。这就是沈青梧能一眼认出程叙的原因。

### 2.4 主角的特殊性：不稳定的视界

程叙和其他观者不同。他的视界**不稳定**——他会在 L0 和 L3 之间随机跳跃。

原因：他天生有**数字联觉（Digital Synesthesia）**。他从小学起就能"看见"数字的形状和颜色，被同学当成怪人。这个天赋让他的视界带宽远超常人，但他从未受过任何训练，所以完全无法控制。

- 平静时：灰蒙蒙一片，什么都看不清
- 专注时：偶尔猛地窜到 L3，然后立刻崩溃
- 危机时：**稳定在 L3**——因为危机让他不再紧张，反而进入了某种绝对专注

**叙事功能**：这是一个完美的戏剧装置。"不稳定"意味着他既能在关键时刻爆发出神级表现，又会在平时显得笨拙狼狈。热血少年向主角需要的正是这个。

#### 补充：半开启（Semi-Vision）

**首次完整开启之后**，观者的视界会变得"更容易漏出来"。

在**极度专注**或**极度疲惫**的状态下，会出现一种中间状态——**半开启**：

| | 完整开启 | 半开启 |
|---|---|---|
| 视觉 | 世界卸载成线框，重新编译成城市 | 现实**褪色**，露出线条轮廓。城市不会升起 |
| 可控性 | 主动，但受带宽限制 | **完全不可控**。什么时候来、什么时候走，观者说了不算 |
| 精神带宽 | 消耗 1 点 | **不消耗** |
| 信息量 | 完整（建筑、人流、依赖连线） | 碎片化。只能看清某一个局部 |
| 持续时间 | 由带宽决定 | 几秒到几分钟，随机 |

**半开启的叙事价值**：它让主角在**不该看见的时候看见**。

他可能在开会时突然看见对面那栋楼在漏水，也可能在写代码时突然看见那个守卫——**而他没有任何办法让它停下来。**

> **程叙在第一卷中的视界记录**：
> - **第 7 章**：不是半开启。只是通道被打开了一条缝（静音 3 秒 + 世界过曝半秒）
> - **第 9 章**：**首次完整开启。** 六步仪式全开，星河城升起
> - **第 15 章**：半开启。盯着代码两小时后，看见守卫与册子，意识到"有些包裹不是重复的"
> - **第 19 章结尾**：半开启。连续两晚未睡，在楼梯间看见光在褪色
> - **第 20 章**：半开启。再次走进老宅，这次是摇摇欲坠的——**但正因为不完整，他看清了那张黄纸上的字**

## 三、视觉法则：技术概念的视界呈现

**这是本 IP 最值钱的部分。** 漫剧美术、游戏美术、周边设计全部从这里取用。

### 3.1 基础映射：一座软件系统就是一座城市

| 现实技术概念 | 视界中的呈现 |
|---|---|
| 单体应用 | 一座巨大的城堡，所有功能挤在城墙里 |
| 微服务 | 一片城邦群，城邦之间靠吊桥和运河相连 |
| 网关 | 城门 + 守门人 |
| 服务注册中心 | 城门口的公告板，写着"今天哪些城邦在营业" |
| 服务调用链 | 城邦之间拉满的钢丝绳，数据像缆车一样来回 |
| 数据库 | 一座金库，里面有无数档案柜 |
| 数据库连接池 | 金库的**门**。只有 N 扇门，同时只能进 N 个人 |
| 缓存（Redis） | 城门口的**临时货棚**，拿东西比进金库快一百倍 |
| 消息队列（MQ） | 一条永不停歇的传送带，或一条运河，货船排队通行 |
| 负载均衡 | 十字路口的调度员，挥着小旗把行人分到不同街道 |
| 日志系统 | 城市的**史官**，坐在塔顶不停记卷轴 |
| 链路追踪 | 一根贯穿全城的**红线**，跟着它可以找到任何一个包裹的全部旅程 |

### 3.2 人物化映射：程序里的"人"

| 现实技术概念 | 视界中的呈现 |
|---|---|
| 线程 | 一个工人 |
| 线程池 | 一支**固定人数**的工人队伍，站在队列前等活。人数是固定的，这是关键 |
| 阻塞（Blocking） | 工人卡在原地，脸色发白，手里还攥着工具 |
| 死锁（Deadlock） | 两个工人面对面站着，各自攥着对方要的钥匙，谁也不松手，永远僵住 |
| 线程饥饿 | 一群工人挤在门口，谁都进不去 |
| 忙等待（自旋） | 工人疯狂地原地跺脚，什么都不干但耗尽全力 |
| 单例（Singleton） | 全城只有一个人能当城主 |
| 代理（Proxy） | 影武者，替真身出面 |
| 观察者模式 | 一群竖着耳朵听钟声的人，钟一响全体转头 |
| GC（垃圾回收） | 巡街的**收尸人**，拖着黑色麻袋，把没人认领的东西收走 |

### 3.3 灾难化映射：故障的视觉表现

| 现实技术概念 | 视界中的呈现 | 漫剧高光指数 |
|---|---|---|
| 慢 SQL | 金库里一个老头在翻箱倒柜，找一个卷轴要半个小时 | ★★ |
| 全表扫描 | 老头把整个金库的档案**全倒在地上**，跪着爬着找 | ★★★ |
| 缺索引 | 图书馆没有目录卡，只能一本一本翻 | ★★ |
| 内存泄漏 | 收尸人走过去，垃圾**还在**，越堆越高，最后堵死整条街 | ★★★ |
| **Full GC / STW** | 收尸人吹响哨子，**全城静止**。所有人、所有水流、所有飘落的纸片，全部定住 | **★★★★★** |
| OOM | 城市被垃圾淹没，天空压下来 | ★★★★ |
| 缓存击穿 | 货棚塌了，所有人同时涌向金库的那一扇门 | ★★★ |
| **缓存雪崩** | 大坝决堤，洪水同时冲垮所有下游城邦 | **★★★★★** |
| 缓存穿透 | 一群人拿着**假证件**，反复冲击同一扇门，门里门外都被撞烂 | ★★★ |
| 布隆过滤器 | 门口的验票员：说"没有"就绝对没有；说"可能有"，还得进去查 | ★★★ |
| 幂等 | 城门守卫只认**第一次**的印章，后面的统统打回 | ★★★ |
| 分布式事务 | 多个城主同时签字，签了一半有人跑路，契约悬在半空 | ★★★★ |
| 消息积压 | 运河堵了，货船排到天边，船上的货全烂了 | ★★★ |
| 熔断 | 一座被主动砍断的吊桥。宁可不过，也不压垮对面 | ★★★★ |
| 限流 | 令牌闸机，一秒只放 N 个人 | ★★ |
| 服务雪崩 | 多米诺骨牌，第一块倒下，整排跟着倒 | ★★★★★ |
| 主从延迟 | 两座城邦之间的时间差。A 城已经发生的事，B 城还没听说 | ★★★ |
| 分布式锁 | 全城唯一的令牌，谁拿到谁能办事 | ★★★ |
| **脑裂** | 一座城市分裂成两半，两边都自称正统，同时发号施令 | ★★★★★ |
| 技术债 | 老城区的**违章搭建**，一层压一层，摇摇欲坠 | ★★★ |
| 祖传代码 | 一座没人敢动的老宅，门上贴着泛黄的纸条："别碰" | ★★★★ |
| Git 冲突 | 两个人在同一面墙上写字，字叠在一起，谁也认不出 | ★★ |
| 回滚 | 时光倒流——但只能倒回上一次快照 | ★★★ |
| 灰度发布 | 只开一条街的新路，看有没有人摔跤 | ★★ |
| 单元测试 | 城门口的质检员，一件件验货 | ★★ |
| CI/CD 流水线 | 一条传送带，把原材料一路送上市中心城楼 | ★★★ |

### 3.4 色彩语言（漫剧团队直接可用）

| 状态 | 主色 | 具体表现 |
|---|---|---|
| 系统健康 | **青蓝** `#2FE0C8` | 数据流平稳，光带柔和 |
| 负载升高 | **琥珀** `#FFB347` | 青蓝渐变到暖黄，光带开始抖动 |
| 濒临危险 | **橙红** `#FF6B3D` | 建筑表面出现裂纹，嗡鸣声变尖 |
| 崩溃中 | **暗红** `#C21F1F` | 画面边缘出现像素撕裂和噪点 |
| **静默者的痕迹** | **纯黑** `#000000` | 不是阴影，是**画面被挖掉了一块**。任何色彩靠近都会被吞掉 |
| 主角觉醒瞬间 | **青白过曝** `#E8FFFF` | 整个世界瞬间过曝，再"编译"成线框 |

### 3.5 音效语言（音频团队直接可用）

| 状态 | 声音设计 |
|---|---|
| 日常 | 无特殊处理，正常环境音 |
| 视界开启 | 环境音被**抽干**，只剩机房风扇的低频嗡鸣（约 60Hz） |
| 健康系统 | 稳定的嗡鸣，像心跳 |
| 负载升高 | 嗡鸣升高半个八度，叠加入微弱心跳 |
| 危险 | 嗡鸣变成尖锐电流声，玻璃摩擦质感 |
| **STW（全城静止）** | 所有声音**瞬间全部消失**。绝对的死寂，持续 3 秒以上。这是全剧最震撼的音效设计 |
| 视界关闭 | 嗡鸣骤停，现实音效"啪"地回来 |

### 3.6 视界开启的固定仪式（招牌镜头）

这是本 IP 的视觉身份证，必须像《火影》结印、《鬼灭》呼吸法一样有辨识度。**每一集都要用同一个分镜节奏**：

```
① 现实中，程叙的手指无意识地敲击——三下。右，左，右。
② 环境音被抽走。世界突然安静得可怕。
③ 瞳孔特写：青色数据流从瞳孔中心炸开，像墨滴入水。
④ 整个世界"卸载"成灰白线框，线条在空中飘浮半秒。
⑤ 线框重新"编译"——城市从地面升起，光带亮起。
⑥ 城门口浮现一行发光的字：SYSTEM ONLINE
```

**第 ⑥ 步的字幕是全剧的招牌彩蛋。** 每一集出现的这行字都会略有不同，暗示当前状态：

- 正常：`SYSTEM ONLINE`
- 负载高：`SYSTEM ONLINE (DEGRADED)`
- 危险：`WARNING: THREAD POOL EXHAUSTED`
- 第一次觉醒：`SYSTEM ONLINE` —— 但底下多了一行小字：`WELCOME, WATCHER.`

## 四、主要人物小传

### 4.1 主角阵营

---

#### 程叙 · 22 岁 · 履约中台组 · 后端开发（应届）

> **名字含义**：谐音"程序"。"叙"是叙述——他既是程序的创造者，也是这个世界的讲述者。

**外形**：165cm，偏瘦，永远穿着洗得发白的格子衬衫。背一个 2015 年款的旧双肩包。头发因为长期熬夜有点毛躁。唯一显眼的是眼睛——非常黑，非常亮，看东西的时候会不自觉地眯起来，像在辨认什么。

**性格**：不是天才型主角，是**较真型**。别人觉得"能跑就行"，他非要搞明白为什么能跑。这份较真让他显得笨、慢、不合群，但也让他成为唯一一个"能看懂"的人。

**口头禅**：
- 「等一下，为什么？」
- 「我再看看日志。」（这是他掩视界的标准借口，后来成了全组的梗）

**前史**：
- 小县城出身，父母开小卖部。高二那年家里老电脑蓝屏，他盯着错误代码看了三个小时，第一次"看见"了东西——一个方方正正的、发着微光的小房间。他以为是自己眼花。
- 大学四年，他一直偷偷记录这些"幻觉"，被室友当成怪人。他不敢告诉任何人。
- 大四实习，投了 87 份简历，只拿到星河科技一个 offer。他把那封邮件截图存了三年。

**能力**：数字联觉 + 不稳定视界（L0↔L3）。
- 平时：一片灰蒙，什么都看不清
- 专注时：突然窜到 L3，立刻崩溃，流鼻血
- 危机时：意外地稳定。因为危机让他进入一种"绝对专注"的状态

**成长弧光**：
> 从"我看见的东西没人信" → 到"我要让别人也能看见"。
>
> 他的终点不是成为最强的观者，而是**把视界还给所有人**。

**核心矛盾**：视界是他最大的秘密，也是他最深的孤独。他想被相信，但他一开口就会被当成疯子。

---

#### 沈青梧 · 27 岁 · 履约中台组技术组长

> **名字含义**：深青色的梧桐。青，是视界的颜色。

**外形**：170cm，永远穿着剪裁利落的深色衬衫，头发在脑后扎成一束。左手腕有一道很浅的旧疤。眼睛是极浅的褐色，在特定光线下会显得接近青色。

**性格**：**用编译器的方式说话**。
- 不说"这个方案可能不太好"，说"这个方案在 QPS 超过 800 时会失效，重新设计"
- 不说"你做得不错"，说"通过"
- 情绪波动幅度小于等于零。全组没人见过她笑。

**但**：她记得每个人家里的事。老赵女儿上小学的日期，周予星对花生过敏，程叙面试时说过"我想搞明白系统为什么会崩"。她只是不说。

**能力**：L2 结构层顶尖。视界开启时，她整个人会被淡青色的光包住，像一层薄雾。

**秘密**：
- 三年前，她也曾不稳定。她曾经在视界里待了太久——**四十分钟**——代价是失去了右耳的全部听力。
- 她的搭档，是纪寒声。
- 她见过 L4 的边缘。她看到了什么，她从来不说。

**口头禅**：
- 「说结论。」
- 「证据。」
- 「再来一次。」

**叙事功能**：她既是程叙的引路人，也是"代价"的证明。她身上写着这个世界的规则：**看见得越多，失去得越多。**

#### 赵大鹏 · 32 岁 · 履约中台组 · 资深业务开发（读者代称"老赵"）

> **叙事功能**：他是**读者的职场翻译官**。任何技术黑话、任何公司潜规则、任何"为什么不能这么干"，都由他用最损的方式讲清楚。

**外形**：178cm，微胖，保温杯里永远泡着枸杞。工位上有四盆绿萝，全部由他救活——都是从别人扔掉的垃圾桶里捡的。桌上摆着一个歪掉的"最佳员工"奖杯，是他自己打印的。

**性格**：**职场老油条，业务活字典**。工作八年，技术一般，但对这套系统的每一个角落了如指掌。他不卷，不加班，到点就走——但他从不甩锅，也从不坑新人。

**金句库**（漫剧的弹幕收割机）：
- 「新人三件事：别乱改代码，别乱说需求，别在群里发表情包。」
- 「这个 Bug 存在两年了。别碰。碰了就是你的了。」
- 「上线不是技术问题，是政治问题。」
- 「我们不生产 Bug，我们只是代码的搬运工。」
- 「什么叫技术债？就是你爸借的钱，要你还。」
- 「产品经理说'就改个按钮'，就像医生说'就割一小刀'。」
- 「淡定。天塌下来有高个子顶着——哦，咱组高个子就是你旁边那位。」
- 「（对着新人）记住了，这个系统能跑，不是因为设计得好，是因为**没人敢动它**。」

**反转时刻**：当程叙被所有人质疑时，第一个站出来的永远是他。因为八年前，也有一个老赵。
**能力**：L1 轮廓层，勉强摸到 L2 的边。他自己不知道这叫视界，他管这叫"手感"。

**叙事功能**：他是"技术理想主义"必须面对的现实。

### 4.2 反派阵营：静默者（The Silencers）

#### 组织理念

> **「我们建造了这座城市。凭什么住在里面的人说了算？」**

**起源**：大静默之后，最早觉醒的一批观者。他们发现在视界里，自己是神——能看见一切，能预判一切。而现实中，他们依然要被不懂技术的甲方、产品经理、总监指手画脚。

**行动纲领**：
1. **证明**：通过制造无可辩驳的重大事故，证明"看不见的人不配管理系统"
2. **筛选**：只有观者才配掌权
3. **终局**：让全世界都"看见"——不管他们愿不愿意

**做事方式**：不留证据、不留署名，只留下**纯黑的痕迹**。受害者事后检查系统，永远找不到任何异常——因为攻击发生在"看不见的层"。

**关键设计**：他们不是来破坏系统的。恰恰相反，**他们每一次攻击，都是在暴露系统真正的弱点**。这让他们难以被简单否定——甚至有些程序员私下认同他们。

**这就是本作最有嚼头的地方**：反派说的有道理，但方式错了。主角要给出的答案不是"打倒他们"，而是"给出第三种可能"。

---

#### 纪寒声 · 33 岁 · 静默者创始人

> **名字含义**：纪，记录；寒声，冷的声音。他是"被听见"的执念的化身。

**外形**：185cm，永远穿黑色的高领。非常干净，非常安静。他走进一个房间，所有人都会不自觉地降低音量。左眼是义眼——**但没有藏起来**。

**性格**：**他不愤怒。这才是最可怕的。**
- 他说话温和，逻辑严密，从不打断别人。
- 他杀一个系统的时候，会先告诉你他要怎么做，然后做到。
- 他对待对手非常尊重。他会认真回答每一个问题，然后依然执行自己的计划。

**能力**：L3 指令层。全剧目前唯一一个能长时间稳定停留在 L3 的人。
- 在视界中，他周围的一切都是**慢的**。他可以慢慢走过去，扶起一个倒下的工人，然后再走回来。
- 但代价是：他为了维持 L3，**主动切掉了自己的一部分记忆**。他不记得母亲的样子。

**前史**：
- 他是沈青梧的搭档。大静默那天，他们在一起。
- 那天夜里他看见了什么，是全书最大的谜团之一。
- 三年前，他在一次 P0 事故中试图说服管理层重构系统，被拒绝了 17 次。第 18 次，他放弃了说服——他直接让系统停了一天。
- 那天之后，他消失了。留下沈青梧和一只失聪的右耳。

**核心台词**：
> 「沈青梧，你还记得那天晚上吗？」
> 「我们看见了整个世界的运行方式。」
> 「然后第二天早上，我们回去写 CRUD。」
>
> 「那一刻我就知道了——**看见真相的人，不应该继续当工具。**」

> 「我不是来毁灭系统的。我是来让所有人**看见**的。
> 手段很痛，我知道。但你们这些年做的事，难道不痛吗？」

**与主角的关系**：他是程叙的**镜像**。同样的天赋，同样的较真，同样的孤独。区别只在于：程叙相信人，纪寒声不再相信了。

**结局设计**（不剧透式表述）：他不是被"打倒"的。他是被**说服**的——但说服他的不是嘴，是程叙做出来的东西。

## 六、写作风格约定

**叙事人称**：第三人称限知，紧贴程叙视角。

**语言风格**：
- 短句为主，节奏快
- **技术描写必须准确**。这是本作可信度的根基，任何一次"瞎编"都会毁掉读者信任
- 幽默来自**真实**，不来自段子。最好的笑点是"这不就是我们公司吗"

**章节长度**：单章 2000–3000 字。每章结尾必须有一个钩子。

**每章必备三要素**：
1. 一个真实的技术点（读者能学到东西）
2. 一个笑点（来自职场真实）
3. 一个钩子（让人点下一章）

**禁止事项**：
- ❌ 主角靠嘴炮说服所有人
- ❌ 视界直接修改现实（违反第一律）
- ❌ 技术术语堆砌而不解释（必须用比喻讲清楚）
- ❌ 反派愚蠢化
