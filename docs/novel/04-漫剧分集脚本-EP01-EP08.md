## 零、改编总纲

### 0.1 三条铁律

**铁律一：不解释，只呈现。**

漫剧没有旁白解释的余裕。任何技术术语**不在台词里被讲出来**，只被"看见"。

| ❌ 错误做法 | ✅ 正确做法 |
|---|---|
| 角色说"这是线程池，它只有二十个线程" | 画面：二十个人在干活，身后几百人排队。**停留 8 秒，零台词** |
| 旁白说"因为超时重试导致重复下单" | 画面：包裹寄出 → 时钟走完 → 包裹退回重发 → 两个包裹同时到达 |
| 角色说"加唯一索引就能解决" | 画面：册子只有一列编号 → 编号多出一列 → 守卫拦住第二个包裹 |

**观众不需要知道"线程池"这三个字。他们只需要看懂"二十个人干活，几百人排队"。**

这是本作的门槛线——**看懂的观众会去查术语，看不懂的观众也看得懂故事**。两者都留下来。

唯一的例外是老赵的台词。因为他说的是**职场吐槽**，不是技术解释。

---

**铁律二：招牌仪式必须复用，且必须变奏。**

"三下敲击 → 静音 → 瞳孔炸开 → 线框卸载 → 城市升起 → `SYSTEM ONLINE`" 是全 IP 的视觉身份证。

但完整仪式**第一季只出现一次**（EP05）。其余七集全部是**剂量递增的预演**。理由很简单：第一次看是震撼，第二次看是重复，第三次看是廉价。

详见 §四 招牌镜头复用表。

---

**铁律三：日常段与特效段的比例不低于 6:4。**

这不只是预算考虑，更是**节奏设计**。日常段是观众的呼吸区，也是情感投资区。没有老赵的贫嘴，就没有 EP08 楼梯间的窒息感。

---

### 0.2 三种分集结构模板

本作不是每集都"事故→爆发"。前 8 集分三类：

#### A 类 · 日常集（EP01 / EP02 / EP03）

```
0–10s    冷开场钩子（黑屏字幕或特写）
10–70s   日常戏：立人物、立关系、埋台词伏笔
70–100s  喜剧节拍（老赵负责）
100–115s 结尾钩子
```

**零特效，成本最低。** 但伏笔密度最高。

#### B 类 · 觉醒集（EP04 / EP05）

```
0–15s    环境音渐弱，进入专注状态
15–40s   推理 / 铺垫（技术可视化，用图形动画而非 3D）
40–60s   半开启或预演
60–100s  完整仪式 + 世界展开（长镜头）
100–120s 结尾钩子（彩蛋字幕）
```

**成本最高。** EP05 是本季预算峰值。

#### C 类 · 行动集（EP06 / EP07 / EP08）

```
0–20s    危机或深入
20–70s    核心段落（技术可视化 / 群像戏）
70–105s   解决与释放
105–130s  结尾钩子
```

**成本中等。** 依赖已建成的城市资产，边际成本可控。

### 0.3 台词风格指南

| 角色 | 台词特征 | 示例 |
|---|---|---|
| **老赵** | 短句、比喻、自嘲。**每集至少两句可做弹幕的** | 「这个系统能跑，不是因为设计得好，是因为没人敢动它。」 |
| **沈青梧** | 极短。几乎不用形容词。命令句为主 | 「说结论。」「证据。」「执行。」 |
| **程叙** | 前半段结巴，后半段突然流畅。**流畅起来就是他"看见了"的信号** | 「我看了日志。」 |
| **周予星** | 毒舌，但落点永远是善意的 | 「你写的是 `status = 1`。吃口香糖吗？」 |
| **孙野** | 只说数字，不评论 | 「每分钟四十七单。」 |
| **韩立冬** | 永远得体，永远在施压。**从不说重话** | 「别紧张，我不是来施压的。」 |

## 三、总体制作约束

### 3.1 术语出现规则（速查）

| 术语 | 出现方式 | 是否被台词说出 |
|---|---|---|
| 线程池 | EP06 第 3–6 镜，视觉呈现 | ✅ 被程叙说出，但**在他"看懂"之后**，且他自己也不知道为什么会说出来 |
| 超时重试 | EP04 第 11 镜，图形动画 | ✅ 被程叙说出（推理段） |
| 唯一索引 | EP07 第 13 镜，册子加一列 | ✅ 被程叙说出 |
| 死锁 | EP06 第 9 镜，背景彩蛋 | ❌ **完全不说** |
| 内存 / GC / 收尸人 | 第三卷 | ❌ |
| 缓存 / 雪崩 | 第二卷 | ❌ |

**原则：术语只在主角"已经看懂"之后才被说出来。** 说出来是结果，不是解释。

### 3.2 招牌镜头复用表

招牌仪式六步：**① 三下敲击 · ② 环境音抽干 · ③ 瞳孔炸开青色数据流 · ④ 世界卸载成线框 · ⑤ 线框编译成城市 · ⑥ `SYSTEM ONLINE`**

| 集 | 用到哪几步 | 变奏方式 | 观众认知状态 |
|---|---|---|---|
| **EP01** | — | 不出现 | 不知道有仪式 |
| **EP02** | ① | **无声植入。**等编译时敲桌子，右左右，程叙自己没注意 | 以为是无聊的小动作 |
| **EP03** | ① | 出现在紧张时刻（咽口水之后敲了一下），**只有一下，不是三下** | 隐约觉得眼熟，但说不清 |
| **EP04** | ①②③（半成品） | 静音发生了（②），世界只"亮"了半秒就恢复，瞳孔 0.2 秒一闪（③未完成） | 意识到**这不正常** |
| **EP05** | **①→⑥ 完整** | 六步全开，长镜头 60 秒 | **恍然大悟**——前四集全部回收 |
| **EP06** | ② | 不做开场仪式。改为**走进建筑内部的瞬间静音 0.5 秒** | 仪式的"城市内"变奏 |
| **EP07** | ② | 顿悟瞬间全城音效消失 1 秒，只剩心跳；心跳落下后也停 | 情绪性变奏——**静默从"进入"变成"理解"** |
| **EP08** | ①（**无②**） | 程叙敲三下 → **什么都没有发生**。因为沈青梧在看着他 | **反仪式**。观众期待落空，立刻明白 |

**设计意图**：完整仪式只出现一次。其余七集是**剂量递增的预演 + 一次反高潮**。这套设计让 120 秒的单集成本可控，又让 EP05 的爆发有足够的铺垫。

### 3.4 预算配比

| 集 | A 类（日常） | B 类（特效） | 场景资产 | 有效成本 | 说明 |
|---|---|---|---|---|---|
| EP01 | 100% | 0% | **新建**：办公室、走廊、前台、会议室 | **低** | 全部资产在 EP02–EP08 复用 |
| EP02 | 95% | 5% | 复用 + **新建**：监控大屏 | 低 | 监控大屏是后续高频复用资产 |
| EP03 | 100% | 0% | 全复用 | **最低** | 单集成本谷底 |
| EP04 | 75% | 25% | 复用 + 闪回独立画风 | 中 | 简笔画闪回的**单位成本约为写实的 1/10** |
| EP05 | 10% | 90% | **新建：星河城全部资产** | **极高** | ⚠️ 全季预算峰值，单独立项 |
| EP06 | 15% | 85% | **全部复用 EP05** + 新建建筑内景 | **中高** | 特效占比高，但资产已建成 |
| EP07 | 20% | 80% | 全复用 | 中 | 同 EP06 |
| EP08 | 80% | 20% | 全复用 | 中 | 降噪处理（褪色线稿）成本低、效果强 |

**关键结论**：

> 真正的烧钱点**只有一个——EP05**。
>
> EP06、EP07 虽然特效占比 80%+，但**边际成本主要来自新镜头，而非新资产**。前 8 集的成本曲线是 **"低 → 低 → 谷底 → 中 → 峰值 → 回落 → 回落 → 中"**，是可控的。

**排期风险提示**：EP05–EP07 连续三集高特效。如果排期紧张，建议**把 EP05 拆成上下两集**（切点在"他穿过了门"），给它一整集的预算空间，同时把 EP06 的内景资产建设顺延。
